# Missables & Collectibles Tracking Format

Sourced from a real walkthrough format ([GameFAQs' NieR Replicant Route A guide by Angelblazer84](https://gamefaqs.gamespot.com/ps4/286768-nier-replicant-ver122474487139/faqs/80036/part-1-route-a)) that does this well: it never makes the player go hunting later for something they could've grabbed in passing.

## The format to copy

At each location/step in the walkthrough, the guide lists **running fraction counters** per collectible category, right where they're obtainable — not in a separate appendix:

- `Weapons - 7/38` with a table of `Item | Where`
- `Words - 12/121` with a table of `Item | Effect | Where`
- `Complete Quests - 16/71` with a table of `Quest | Where`

The counter climbing (7/38 → 8/38 → 9/38...) as the walkthrough progresses is what makes it usable *during* a session — the player always knows both what to grab right now and how many are left overall, without cross-referencing a master list.

Layered on top, inline callouts flag anything time-sensitive or non-obvious exactly where it applies:
- Rare/RNG drops: *"Save at the entrance and reload if it doesn't spawn"*
- Farmable windows: *"This stays farmable as long as you don't progress the story or complete a quest"* — i.e. an explicit warning that a specific action closes the window
- Missable choices: which dialogue/action branch preserves vs. forecloses a collectible or trophy

## Applying this in a plan

When the user wants missables tracked (not just "collect things along the way"), build a **per-session tracker** using this shape: for each session in the weekly loop, list the running fraction counters for whatever collectible categories the game has (weapons/trophies/items/etc.), sourced from a real collectibles/missables guide the same way chapters are sourced from a walkthrough (see `pacing.md`) — don't invent counts. Attach inline callouts for anything rare, timed, or choice-gated.

## Structurally-required replays are not a planning failure

Some games are *designed* around multiple full playthroughs as their actual narrative structure (NieR-style Route A/B/C/D/E, NG+-gated true endings, some visual novels). That's different from an *avoidable* replay caused by a missed item. When a game has this structure:

- Treat each route/playthrough as its own numbered phase in the loop (Route A, Route B, ...), not as a failure to plan around.
- Within each individual route, still apply the normal rule — front-load that route's own missables so nothing gets missed *inside* it.
- Say this distinction out loud in the plan: "this game requires N full playthroughs by design; here's what's new/different each time" — so the person isn't surprised or reading it as wasted effort.
